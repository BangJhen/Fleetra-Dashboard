# Ilustrasi autentikasi FLEETRA

Dibuat menggunakan tool imagegen bawaan, bukan fallback CLI.

Aset proyek: `public/images/fleetra-auth-illustration.png`

Dipakai pada panel pengantar halaman Login dan Register. Gambar tetap disimpan di proyek; Next.js Image mengoptimalkan ukuran pengiriman sesuai viewport.

Prompt final:

> Create a refined raster editorial illustration asset for the left panel of FLEETRA, an Indonesian fleet logistics management web application's login and registration pages. This is the illustration asset ONLY, not a website mockup. Landscape composition approximately 3:2. An architecturally precise white light commercial cargo delivery van, with restrained cobalt-blue #2463D8 body accents, in three-quarter view pointing to the right. In the midground a small contemporary logistics warehouse with loading bays, a second much smaller van, and understated Bandung-inspired low-rise city silhouettes. A clean curved roadway leads through the scene, conveying coordinated fleet movement. Polished two-dimensional editorial rendering with fine technical contours and very restrained geometric shading, mature B2B logistics aesthetic. Use only Fleetra blue #2463D8, darker blue #1E57C7, pale blue #EAF3FF, slate blue-grey #64748B, white and near-white #F4F8FC. Solid very pale blue #F4F8FC background, generous clean margins, no enclosing frame. Make the vehicles and warehouse large enough to read at a 450 pixel display width, composition balanced horizontally, visible wheels and sensible vehicle geometry. Do NOT include any text, letters, numbers, logos, watermark, infographic labels, floating UI cards, dashboards, map pins, dots, network nodes, neon, gradients, glows, glassmorphism, cartoon characters, glossy plastic toy or inflated 3D styling. The image should sit naturally below a typography block in a quiet white/light-blue interface.
